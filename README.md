# Skin Cancer Detection Using Deep Learning

An automated skin lesion classification web application built with **PyTorch** and **Flask**, combining **ResNet-18** and **MobileNetV2** into an ensemble model to classify 14 types of skin lesions.

## Model Performance
- **ResNet-18 Validation Accuracy:** 75.66%
- **MobileNetV2 Validation Accuracy:** 79.13%
- **Ensemble (ResNet-18 + MobileNetV2) Validation Accuracy:** 81.07%

## How to Run Locally
```bash
pip install -r requirements.txt
python app.py
```
